← Back to homeVOICE FOLLOWING

You speak. It follows.

Oralo uses on-device speech recognition to match the script you are using and mark where you are.

Keep pace with your script

When you pause, it waits. When you continue from the script, it moves forward with you.

Find a way back

After you step away, it may try to return to the same sentence or a nearby later line only if it clearly recognizes the original wording. It does not promise to find your place automatically from any part of the script.

You can select a line yourself at any time. If you do, that choice takes priority.

What affects recognition

Noise, distance, other voices, your device, and language all affect recognition. Results vary with these conditions.

Using Oralo offline

Script editing and reading use data on your device. Voice following needs a supported system speech model already downloaded; the first download of a model or voice may require the internet. If on-device recognition is unavailable, you can still prompt manually, and the app will not send audio to a cloud recognizer instead.

The on-site preview uses no microphone. Voice following happens in the app.

How the floating prompt works ↗

A few things to know.

If I pause or speed up, will it stay with me?

It is designed to wait when you pause and to follow when you continue from the script. How steady that feels depends on your environment, device, language, and installed system model.

Will it bring me back automatically after I go off script?

It only tries to return to the same sentence or nearby lines, and only when it clearly recognizes the original wording. It does not guarantee an accurate return from any point in the script. You can always choose a line yourself.

Can I use voice following offline?

If the system model is already on your device, voice following can run on-device. The first download of a model or voice may need the internet. This is not a claim that every feature works fully offline, or that offline use has been independently verified end to end.
