STEP-BY-STEP GUIDE

Floating teleprompter for iPhone & iPad

Put your script in a Picture-in-Picture window on iPhone or iPad. Choose a steady scroll or voice following, then switch apps. This guide covers both paths, interruption recovery and the setups that have actually been checked.

1. Open the floating-prompt controls

  1. Prepare your script

    Open a saved script, or tap New script → Paste text in the library. On Prepare, use (…) → Speech language to match the language if you plan to use voice following.

  2. Enter Floating prompt

    On Prepare, open the top-right (…) menu → Floating prompt. Choose Fixed pace or Voice follow. Close an active floating window before changing modes.

2A. Use fixed-pace scrolling

A steady scroll without microphone access. Start here if you want to set the speed yourself.

  1. Choose your starting point

    Select Fixed pace. Tap Choose passage, then a sentence. Adjust Scrolling speed and Text size. Preview scrolling lets you check the pace inside Oralo; Pause preview stops the preview.

  2. Open the window, then switch apps

    Tap Open floating window. A three-second countdown starts before the text scrolls. Switch to the app you want to use while keeping the window visible.

  3. Check the framing

    Move the system Picture-in-Picture window away from important controls. If Camera tucks it against an edge, tap the edge arrow to bring it back. Pinch to resize within the sizes allowed by the system.

2B. Let the window follow your voice

Prepare voice following while Oralo is still in the foreground, before switching to another app.

  1. Select Voice follow

    With the window closed, select Voice follow. Use Choose passage to set your starting sentence and Text size to make it readable.

  2. Test a sentence in Oralo

    Tap Try voice following. Allow requested permissions and use Download speech model and retry or Retry with compatibility recognition if offered. Read a sentence and check the position before you leave Oralo.

  3. Open the window

    Tap Open floating window. Wait for voice preparation to finish and the window to open, then switch apps. Read a few lines in the other app before starting a longer take.

Fixed pace and Voice follow are separate modes. If microphone input is interrupted, voice mode holds your place; it does not silently change into timed scrolling.

3. Return, restart, or fix an interruption

  • The script stops following

    Return to Oralo. If needed, close the floating window, choose the passage again and tap Try voice following. Check a sentence, then open the window again. If the other app keeps interrupting input, close the window and switch to Fixed pace.

  • You return to Oralo

    Returning pauses the prompt and stops voice capture. Start the preview or voice check again when you want to resume. Returning to the Floating prompt screen alone does not restart listening.

  • The window closes or cannot open

    Picture-in-Picture availability and placement are controlled by the system and the other app. Return to Oralo and try Open floating window again. If unavailable, use the in-app preview or full-screen prompting.

A few things to know.

Where do I find Floating prompt?

Open a script in Oralo. On Prepare, tap the top-right (…) menu → Floating prompt. It is a separate entry from the Start speaking button.

Can I use it with Camera, a livestream or a call?

System Camera photo preview was checked on iPhone 15 Pro with iOS 18.1. Separate device feedback confirmed following during recording and normal recorded speech, without a full device/app matrix. Livestream and calling apps are not covered; test your own setup and play back a short recording first.

Does returning to Oralo keep the microphone running?

No. Returning pauses the prompt and stops voice capture. Check voice following again in Oralo before reopening the window and switching apps. If another app repeatedly interrupts input, try Fixed pace, which uses no microphone.
